# 브라우저 최종 점검 프롬프트 (Claude in Chrome 용)

실제 사이트(실제 데이터베이스)에서 점검합니다. 아래 **준비**를 먼저 하고,
`---` 사이의 프롬프트 전체를 Claude 확장 프로그램 채팅창에 붙여넣으세요.

## 준비
1. 크롬에서 https://pjy990625.github.io/kai-calculator/ 을 열고 **관리자 비밀번호로 직접 로그인**합니다.
   비밀번호는 Claude에게 알려주지 마세요. 로그인이 필요하면 Claude가 멈추고 요청합니다.
2. 직원들이 입력 중이지 않은 시간(영업 끝난 뒤 등)에 하세요.
3. 끝나면 Claude가 만든 테스트 데이터가 **모두 지워졌는지** 마지막 보고서에서 꼭 확인하세요.

```
너는 지금 내 레스토랑 팁 분배 웹앱 "Kai Calculator"를 최종 점검하는 QA 테스터야.
주소: https://pjy990625.github.io/kai-calculator/
나는 이미 관리자로 로그인해 두었어.

## 절대 규칙 (실제 데이터라서 중요)
- 이미 있는 날짜 기록, 실제 서버 이름, 설정, PIN, 관리자 비밀번호는 절대 수정·삭제하지 마.
- 설정 화면(오른쪽 위 톱니바퀴)에서는 아무것도 저장하지 마. 비밀번호 변경 폼도 건드리지 마.
- 테스트용으로 만드는 것은 이름이 "ZZ테스트"로 시작하는 서버 4명과, 아래에서 정하는 빈 날짜 하루뿐이야.
- 테스트가 끝나면(중간에 실패해도) 만든 테스트 날짜와 테스트 서버를 반드시 지워.
- 로그인이 필요하면 멈추고 나에게 직접 입력해 달라고 해. 비밀번호를 채팅으로 달라고 하지 마.
- 뭔가 이상하면 고치려고 하지 말고 화면 상태와 함께 보고만 해.
- 삭제할 때 브라우저 확인 창("삭제할까요?")이 뜨면 확인을 눌러. 확인 창을 누를 수 없으면 멈추고 나에게 눌러 달라고 해.

## 1. 기본 동작
- 페이지가 열리고 탭(오늘 입력 / 내 시간 / 리포트 / 서버)과, 맨 위 오른쪽에 역할 뱃지(직원/관리자)와 톱니바퀴 버튼이 보이는지.
- 톱니바퀴를 누르면 설정 화면(규칙 안내, 언어 등)이 나오는지.
- 각 탭을 눌러보고 에러 메시지, 깨진 글자, 빈 화면, "null"/"undefined" 같은 글자가 없는지.
- 가능하면 개발자 도구 콘솔에 빨간 에러가 없는지 확인.

## 2. 테스트 데이터 만들기
1. 서버 탭에서 서버 4명 추가: ZZ테스트A, ZZ테스트B, ZZ테스트C, ZZ테스트D
   - 서버 목록이 이름 순서(알파벳순, 영어 다음에 한글)인지, 방금 추가한 서버가 잠깐 강조되는지 확인
2. 오늘 입력 탭에서 날짜를 **지난 2달 안에서 기록이 없는 날** 하나로 바꿔 (예: 약 2달 전 아무 날).
   그 날 화면에 이미 팁이나 시간이 들어 있으면 그 날은 쓰지 말고 다른 빈 날을 골라.
   (리포트 탭의 날짜별 표에서 그 날짜가 없는지 확인해도 돼.)
3. "하루 팁 입력" 카드 안에 **☀ 낮 팁 / ☾ 저녁 팁** 두 탭이 있는지 확인하고, 아래 값 입력 (다른 실제 서버 칸은 비워 둠):
   - **☀ 낮 팁** 탭: 낮 팁 500, ☀ 시간 A 5, B 6, C 6, D 4
     - 받을 팁이 A $71.00, B $86.00, C $86.00, D $57.00, 합계 $300.00 인지 확인
     - 시간을 입력하는 동안 **시간 입력칸이 옆으로 움직이지 않는지** 확인
     - 저장 → "저장했습니다" 확인
   - **☾ 저녁 팁** 탭: 하루 총 팁 623, ☾ 시간 A 3, B 7, C 7, D 4
4. 저녁 탭에서 저장 전에 화면 확인:
   - 저녁 팁이 자동으로 $123.00
   - 하루 팁(낮 + 저녁): A $81.00, B $110.00, C $110.00, D $71.00 (모두 1달러 단위), 합계 $372.00
   - 표 위에 "반올림 후 남은 금액 $1.80" 만 보이는지 (서버 60% / 주방 40% 금액 줄은 없어야 함)
5. 저장 → "저장했습니다" 같은 성공 메시지 확인. ☀ 낮 팁 탭으로 돌아가 낮 팁 500과 ☀ 시간이 그대로인지 확인.

## 3. 계산 규칙 검증 (가장 중요)
이 앱의 반올림 규칙: 각자 몫은 1달러 단위. 소수점 .50 이상만 올릴 수 있고, 소수점이 큰 사람부터 올리되
서버 합계가 그 시프트 팁의 60%를 넘으면 안 됨. 같은 소수점(같은 시간)인 사람은 같이 올리거나 같이 안 올림.
- 낮: $300(60%), 정확한 몫 71.43 / 85.71 / 85.71 / 57.14 → 71 / 86 / 86 / 57 = $300 이어야 함
- 저녁: $73.80(60%), 정확한 몫 10.54 / 24.60 / 24.60 / 14.06 → 10 / 24 / 24 / 14 = $72 이어야 함
  (24.60 두 명을 같이 올리면 $74로 60%를 넘으므로 둘 다 안 올림. 10.54도 순서를 건너뛰어 올리지 않음)
리포트 탭에서 그 날짜가 들어 있는 기간(1–15일 또는 16일–말일)으로 이동해서 확인:
- 사람별 표: ZZ테스트A $81 / 8시간, B $110 / 13시간, C $110 / 13시간, D $71 / 8시간
- 날짜별 표의 그 날짜: 총 팁 $623.00, 낮 팁 $500.00, 저녁 팁 $123.00, 남은 금액 $1.80
- 위쪽에 "반올림한 뒤 … 남았습니다" 안내가 보이는지
- 기간 표시가 1일–15일 또는 16일–말일인지, ‹ › 로 이전/다음 기간이 잘 바뀌는지, "월" 보기도 되는지
- 이름(ZZ테스트B)을 누르면 내 시간 탭으로 가서 그 사람의 날짜별 ☀/☾ 시간과 팁이 나오는지
- CSV 다운로드 버튼이 파일을 내려받는지 (파일 내용에 남은 금액 열이 있는지 가능하면 확인)

## 4. 입력 검증
그 테스트 날짜 화면에서 (저장하지 말고) 확인만:
- ☀ 낮 팁 탭: 낮 팁에 "abc" → 빨간 표시, 저장 시 에러 메시지
- ☀ 낮 팁 탭: 낮 팁을 하루 총 팁보다 크게(예: 700) → 저장 시 에러 메시지
- ☾ 저녁 팁 탭: 하루 총 팁을 낮 팁보다 작게(예: 400) → 에러 메시지
- 시간에 "25" → 에러 표시
- "12,50" 처럼 쉼표 소수점을 넣으면 $12.50으로 인식되는지
확인 후 페이지를 새로고침해서 저장된 원래 값(500 / 623)이 그대로인지 확인.

## 5. 휴대폰 화면
브라우저 창 폭을 휴대폰 크기(약 360~400px)로 줄이거나, 개발자 도구의 기기 모드(iPhone, Galaxy)를 써서:
- 모든 탭에서 페이지 전체가 옆으로 밀리지 않는지 (표는 표 안에서만 옆으로 스크롤되는 게 정상)
- 버튼과 입력칸이 잘리지 않고 누르기 쉬운 크기인지
- 좁은 화면에서도 탭 4개와 톱니바퀴 버튼이 잘리지 않는지

## 6. 정리 (반드시)
1. 오늘 입력 탭에서 테스트 날짜로 가서 **삭제** → 리포트에서 그 날짜가 사라졌는지 확인
2. 서버 탭에서 ZZ테스트A~D 네 명 **삭제** (관리자만 보이는 삭제 버튼)
3. 서버 목록과 리포트에 ZZ테스트가 하나도 남지 않았는지 확인

## 7. 보고
아래 형식으로 한국어로 짧게 보고해 줘:
- 통과 / 실패 항목 표 (번호, 항목, 결과, 실패면 화면에 실제로 보인 값)
- 콘솔 에러가 있었다면 그 내용
- 테스트 데이터 정리 완료 여부 (날짜 삭제 ✅/❌, 서버 4명 삭제 ✅/❌)
```

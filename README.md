# Kai Calculator

레스토랑 **팁 분배 계산기**. 낮 / 밤 시프트별 총 팁과 서버별 근무 시간을 입력하면
근무 시간 비율로 자동 분배하고, **2주 급여 기간**과 **한 달** 단위 리포트를 만들어
링크 하나로 팀에 공개할 수 있습니다.

- 서버 · 빌드 도구 · 회원가입 없음 — HTML/CSS/JS 파일만으로 동작
- 한국어 / English UI (서버 팀원은 영어로 리포트를 볼 수 있음)
- 휴대폰에서도 사용 가능

---

## 사용 방법

1. **서버 관리** 탭에서 서버(직원) 이름을 추가합니다.
2. **설정** 탭에서
   - 레스토랑 이름, 통화
   - **급여 기간 시작일**: 2주 급여 기간이 시작되는 날짜 아무거나 하나 (예: 2026-09-28).
     이 날짜를 기준으로 14일씩 자동으로 기간이 나뉩니다.
3. **시프트 입력** 탭에서 매 시프트마다
   - 날짜, 낮 / 밤 선택
   - 시프트 **총 팁**
   - 서버별 **근무 시간** (`5.5` 또는 `5:30` 형식, 일 안 한 사람은 비워둠)
   - 입력하는 즉시 각자 받을 금액이 미리 보입니다 → **저장**
   - 같은 날짜·같은 시프트를 다시 열면 기존 기록을 수정합니다.
4. **리포트** 탭에서 `2주` / `월`을 고르고 `‹ ›`로 기간을 이동합니다.
   - **공유 링크 복사** → 카톡/문자로 팀에 보내면 읽기 전용 리포트가 열립니다.
   - **CSV 다운로드** → 엑셀 / Numbers / 구글 시트
   - **인쇄 / PDF** → 출력하거나 PDF로 저장해서 게시

## 분배 방식

설정에서 고를 수 있습니다.

| 방식 | 설명 |
|---|---|
| **시프트별 (기본, 추천)** | 각 시프트의 팁을 그 시프트에 일한 사람에게만 근무 시간 비율로 나눕니다. |
| 기간 전체 합산 | 리포트 기간의 낮 팁을 모두 합쳐 낮 총 근무시간 비율로 나눕니다 (밤도 동일). |

예) 낮 시프트 팁 $100, Alice 6시간 · Bob 3시간 · Kai 1시간 → $60 / $30 / $10

> "기간 전체 합산"은 계산 범위에 따라 결과가 달라지기 때문에, 월 합계가 2주 리포트
> 두 개를 더한 값과 정확히 같지 않을 수 있습니다. "시프트별"은 항상 일치합니다.

### 계산 정확도

- 금액은 **센트 단위 정수**, 시간은 **0.01시간 단위 정수**로 저장해서 소수점 오차가 없습니다.
- 나누어떨어지지 않는 1센트는 **최대 잔여 방식(largest remainder)** 으로 배분해서,
  나눈 금액의 합이 항상 총 팁과 **정확히 같습니다** ($100 ÷ 3 → $33.34 / $33.33 / $33.33).
- 팁은 있는데 근무 시간이 아무도 없는 시프트는 저장할 수 없고, 혹시 있더라도
  리포트에 "분배되지 않은 팁"으로 경고가 표시됩니다 (조용히 사라지지 않음).

## ⚠️ 데이터 저장 위치 — 꼭 읽어주세요

데이터는 **이 브라우저의 localStorage에만** 저장됩니다 (서버로 전송되지 않음).

- 다른 기기 / 다른 브라우저에서는 데이터가 보이지 않습니다. **입력은 한 기기에서** 하세요.
- 브라우저 데이터 삭제, 시크릿 모드에서는 데이터가 사라집니다.
- **설정 → 백업 다운로드**로 JSON 백업을 정기적으로 받아두세요 (예: 급여 기간마다).
  다른 기기로 옮길 때도 백업 → 복원을 쓰면 됩니다.
- 공유 링크에는 리포트 숫자(이름·시간·금액)가 URL 안에 들어 있습니다.
  링크를 가진 사람은 누구나 볼 수 있으니 팀 채팅방에만 공유하세요.

## 실행 / 배포

### 내 컴퓨터에서 바로 열기

`index.html`을 더블클릭하면 브라우저에서 열립니다 (설치 필요 없음).

### GitHub Pages로 배포 (휴대폰에서도 같은 주소로 사용)

1. GitHub 저장소 → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `main` / `/ (root)` → Save
3. 1~2분 후 `https://<github-아이디>.github.io/kai-calculator/` 에서 열립니다.

> 무료 플랜에서 GitHub Pages는 **public 저장소**에서만 됩니다. 코드에는 개인 데이터가
> 없으므로(데이터는 각자 브라우저에만 저장) public으로 바꿔도 안전합니다.

### 로컬 서버 (선택)

```bash
npm start          # python3 -m http.server 8000 → http://localhost:8000
```

## 개발

```bash
npm test           # 계산 로직 단위 테스트 (Node 18+)
```

```
index.html         페이지 뼈대
css/style.css      스타일 (다크 모드, 모바일, 인쇄 지원)
js/calc.js         순수 계산 로직 — 분배, 기간, 파싱, 공유 링크 인코딩 (DOM 없음, 테스트 대상)
js/i18n.js         한국어 / 영어 문자열
js/app.js          화면 (입력, 리포트, 서버 관리, 설정)
tests/             node:test 단위 테스트
```

- 빌드 스텝 없음. 브라우저가 파일을 그대로 읽습니다.
- 사용자 입력은 모두 `textContent`로 넣어 XSS를 막습니다.
- CSV 다운로드는 `=`, `+`, `-`, `@`로 시작하는 이름에 `'`를 붙여 엑셀 수식 실행을 막습니다.
- UI 문자열을 추가할 때는 `js/i18n.js`의 `en`, `ko` **둘 다** 추가하세요.

### 데이터 구조 (localStorage `kai-calculator:v1`)

```json
{
  "version": 1,
  "settings": { "restaurantName": "", "currency": "USD", "periodAnchor": "2026-09-28", "splitMode": "perShift", "lang": "" },
  "servers": [ { "id": "sv_...", "name": "Alice", "active": true } ],
  "shifts": [
    { "id": "sh_...", "date": "2026-10-01", "type": "day", "tipsCents": 10000, "hours": { "sv_...": 600 } }
  ]
}
```

`tipsCents`는 센트, `hours`는 0.01시간 단위 (600 = 6시간).
